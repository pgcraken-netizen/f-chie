## PC／スマホの切り替え
- 画面幅で自動的にPCレイアウト／スマホレイアウトに切り替わります（767px以下でスマホ）。
- 画面左下の「表示：自動／PC／スマホ」ボタンで手動切替できます。
  - PCで「スマホ」を押すと、幅430pxのスマホ表示で確認できます。
  - スマホで「PC」を押すと、PCレイアウトで表示します。
  - 選んだ表示はブラウザに記憶されます。「自動」で元に戻ります。
- 仕組み：`.page` のコンテナクエリ（@container）でレイアウトを切り替えています。

## v2.2 の改善（2026-10-26）
- トップを「理念 → 暮らしの3政策 → 具体的な取り組み → プロフィール → お知らせ・研究会 → お問い合わせ」の順に再編
- ファーストビューに活動領域（子ども・健康・地域の支え合い）と「プロフィール」「政策を見る」の2つの入口
- 政策カード：日本語名を主、カタカナ名を副にし、「暮らしの困りごと」の声と一文の説明、「詳しく見る」を追加
- 取り組みカード：状態（実施中／提案中）、時期、事業主体・協働先、出典を明記
- 経歴表記：「19年」をやめ「2007年初当選、2015年に再当選。現在5期目」に。プロフィールに2013年の辞職を明記
- 「3つのゼロ」は本人未承認のため削除
- 本文16px・補助文字のコントラスト強化、電話はタップで発信できる大きなボタン、押した後の動作を明記
- スマホは画面下部に常時表示のメニュー（ホーム／プロフィール／政策／実績／お問い合わせ）
- 最終更新日をお知らせ欄とフッターに表示。表示切替ボタンはフッター内へ移動
- 未開設のInstagram・YouTubeリンクは削除
