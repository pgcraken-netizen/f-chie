## PC／スマホの切り替え
- 画面幅で自動的にPCレイアウト／スマホレイアウトに切り替わります（767px以下でスマホ）。
- 画面左下の「表示：自動／PC／スマホ」ボタンで手動切替できます。
  - PCで「スマホ」を押すと、幅430pxのスマホ表示で確認できます。
  - スマホで「PC」を押すと、PCレイアウトで表示します。
  - 選んだ表示はブラウザに記憶されます。「自動」で元に戻ります。
- 仕組み：`.page` のコンテナクエリ（@container）でレイアウトを切り替えています。
